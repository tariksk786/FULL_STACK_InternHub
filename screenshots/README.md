# InternHub — Application Screenshots

This directory contains visual captures of InternHub's frontend interface across different viewport sizes and interaction states:

1. `desktop-portal-overview.png`: Main internship listings view showing search bar, active domain filters, and responsive opportunity cards.
2. `accessible-application-modal.png`: Native HTML5 modal dialog with accessible labels, input hints, live character counter, and privacy notice.
3. `validation-and-error-states.png`: Inline form validation error highlights and server rate limit alert banner.
4. `submission-success-view.png`: Application submission confirmation screen displaying unique reference ID (`#APP-XX`).
5. `empty-and-failure-states.png`: Empty state with "Reset Filters" action and failure state with "Retry" action.
